# План внедрения проекта «Запас»

Мы предлагаем трёхэтапный план запуска продукта, начиная с пилотного проекта на базе банка-партнёра (например, ВТБ). Как Product Manager, я структурировал этот план для минимизации рисков и постепенного масштабирования.

## Этап 1: MVP и пилотный запуск (Месяцы 1–3)
- **Цель**: Проверить гипотезу на реальной аудитории и отладить алгоритм `Decide()`.
- **Действия**:
  1. Интеграция нашего движка с песочницей (sandbox) API банка-партнёра.
  2. Запуск закрытого бета-тестирования среди 500–1000 студентов Финансового университета и молодых клиентов ВТБ.
  3. Сбор обратной связи и калибровка порогов безопасности (отклонение дохода, размер буфера).
- **Ресурсы**: Наша команда из 3 человек (разработка, аналитика, ИБ).

## Этап 2: Масштабирование и полная интеграция (Месяцы 4–8)
- **Цель**: Выход на широкую аудиторию внутри приложения банка.
- **Действия**:
  1. Публикация функции «Запас» как отдельной вкладки в мобильном приложении.
  2. Запуск маркетинговой кампании: «Копи умно, не уходи в минус».
  3. Подключение ML-модели для более точного предсказания регулярных платежей (вместо простой медианы).
- **Ресурсы**: Подключение команд маркетинга и мобильной разработки банка.

## Этап 3: Монетизация и развитие (Месяцы 9–12)
- **Цель**: Выход на операционную окупаемость.
- **Модель монетизации**:
  - **B2C**: Бесплатно для базового использования. Премиум-подписка (99 ₽/мес) за расширенную аналитику и мульти-копилки.
  - **B2B**: Продажа технологии «безопасного скоринга накоплений» другим банкам как SaaS-решение (White Label).
